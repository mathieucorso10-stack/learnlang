# Leçon 5 — Nombres, heure et date

## Les nombres de 0 à 20

| # | Espagnol |
|---|---|
| 0 | cero |
| 1 | uno |
| 2 | dos |
| 3 | tres |
| 4 | cuatro |
| 5 | cinco |
| 6 | seis |
| 7 | siete |
| 8 | ocho |
| 9 | nueve |
| 10 | diez |
| 11 | once |
| 12 | doce |
| 13 | trece |
| 14 | catorce |
| 15 | quince |
| 16 | dieciséis |
| 17 | diecisiete |
| 18 | dieciocho |
| 19 | diecinueve |
| 20 | veinte |

À partir de 16, le nombre se construit "**diez + et + unité**" collé en un
seul mot : **dieciséis** = "diez y seis" (dix-et-six).

## De 21 à 100

- 21-29 : même logique, un seul mot : **veintiuno, veintidós, veintitrés**...
  jusqu'à **veintinueve**.
- 30, 40, 50... : **treinta, cuarenta, cincuenta, sesenta, setenta, ochenta,
  noventa, cien**.
- À partir de 31 : les dizaines et unités se séparent avec **y** ("et") :
  **treinta y uno** (31), **cuarenta y dos** (42), **noventa y nueve** (99).

⚠️ Différence avec le français : pas de "quatre-vingts" ni de "soixante-dix"
bizarres — chaque dizaine a son propre mot, régulier.

## Les grands nombres

- 100 = **cien** (mais **cien libros** = 100 livres ; **ciento uno** = 101)
- 200 = **doscientos**, 300 = **trescientos**... (s'accorde en genre : *doscientas
  personas*)
- 1 000 = **mil**
- 1 000 000 = **un millón**

## Dire l'heure (avec SER, souviens-toi de la leçon 4 !)

- **¿Qué hora es?** → Quelle heure est-il ?
- **Es la una.** → Il est une heure. (singulier, une seule heure → *es*)
- **Son las dos.** → Il est deux heures. (pluriel → *son*)
- **Son las tres y media.** → Il est trois heures et demie.
- **Son las cuatro y cuarto.** → Il est quatre heures et quart.
- **Son las cinco menos cuarto.** → Il est cinq heures moins le quart.
- **Es mediodía. / Es medianoche.** → Il est midi. / Il est minuit.

## Les jours de la semaine

| Espagnol | Français |
|---|---|
| lunes | lundi |
| martes | mardi |
| miércoles | mercredi |
| jueves | jeudi |
| viernes | vendredi |
| sábado | samedi |
| domingo | dimanche |

⚠️ En espagnol, les jours de la semaine **ne prennent pas de majuscule**.
Autre point : l'article se met devant le jour pour dire "le lundi"
(habituel) : **los lunes** (le lundi, habituellement).

## Dire la date

**Hoy es lunes, 26 de julio de 2026.** → Aujourd'hui, c'est lundi 26
juillet 2026.

Structure : **[jour] + [numéro] + de + [mois] + de + [année]**. Contrairement
au français, pas de "premier" spécial : même le 1er se dit **el uno de
enero** (parfois *el primero* en Amérique latine).

## Phrases à retenir

- **Tengo veintiocho años.** (J'ai vingt-huit ans.)
- **Mi cumpleaños es el quince de mayo.** (Mon anniversaire est le 15 mai.)
- **Nos vemos el jueves a las siete.** (On se voit jeudi à sept heures.)
- **La tienda abre a las nueve y cierra a las ocho.** (Le magasin ouvre à
  9h et ferme à 20h.)
