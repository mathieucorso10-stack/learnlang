# Leçon 3 — Articles, genre, pluriel et verbes réguliers

## Les articles définis (le, la, les)

| Espagnol | Français |
|---|---|
| **el** libro (masc. sing.) | le livre |
| **la** casa (fém. sing.) | la maison |
| **los** libros (masc. plur.) | les livres |
| **las** casas (fém. plur.) | les maisons |

**Tous les noms ont un genre** (masculin/féminin), et l'article s'accorde.
Règle pratique très fiable :
- mots terminés en **-o** → très souvent masculins (**el libro**)
- mots terminés en **-a** → très souvent féminins (**la casa**)
- ⚠️ exceptions à connaître : **el día** (le jour, masc. malgré le -a),
  **la mano** (la main, fém. malgré le -o).

## Les articles indéfinis (un, une, des)

| Espagnol | Français |
|---|---|
| **un** libro | un livre |
| **una** casa | une maison |
| **unos** libros | des livres |
| **unas** casas | des maisons |

## Le pluriel

Règle simple :
- mot terminé par une voyelle → on ajoute **-s** : **libro → libros**
- mot terminé par une consonne → on ajoute **-es** : **profesor → profesores**

## Les verbes réguliers : trois groupes

L'espagnol a trois groupes de verbes à l'infinitif : **-ar**, **-er**,
**-ir**. La logique de conjugaison au présent est régulière et se retient
vite.

### Groupe 1 : -AR — hablar (parler)

| | Espagnol |
|---|---|
| yo | habl**o** |
| tú | habl**as** |
| él/ella/usted | habl**a** |
| nosotros | habl**amos** |
| vosotros | habl**áis** |
| ellos/ustedes | habl**an** |

### Groupe 2 : -ER — comer (manger)

| | Espagnol |
|---|---|
| yo | com**o** |
| tú | com**es** |
| él/ella/usted | com**e** |
| nosotros | com**emos** |
| vosotros | com**éis** |
| ellos/ustedes | com**en** |

### Groupe 3 : -IR — vivir (vivre)

| | Espagnol |
|---|---|
| yo | viv**o** |
| tú | viv**es** |
| él/ella/usted | viv**e** |
| nosotros | viv**imos** |
| vosotros | viv**ís** |
| ellos/ustedes | viv**en** |

👉 Astuce : les terminaisons -ER et -IR ne diffèrent qu'à **nosotros**
(-emos / -imos) et **vosotros** (-éis / -ís). Partout ailleurs, c'est
identique. Beaucoup plus simple qu'en français !

## Quelques verbes réguliers utiles à connaître déjà

- **hablar** (parler) — *hablo español* (je parle espagnol)
- **estudiar** (étudier)
- **trabajar** (travailler)
- **comer** (manger)
- **beber** (boire)
- **leer** (lire)
- **vivir** (vivre, habiter) — *vivo en París* (j'habite à Paris)
- **escribir** (écrire)
- **abrir** (ouvrir)

## La négation

Rien de plus simple : on place **no** juste avant le verbe.
- **No hablo español.** → Je ne parle pas espagnol.
- **No vivo en Madrid.** → Je n'habite pas à Madrid.

Contrairement au français (« ne...pas »), un seul mot suffit.

## Phrases à retenir

- **Hablo un poco de español.** (Je parle un peu espagnol.)
- **¿Hablas inglés?** (Tu parles anglais ?)
- **Vivimos en Barcelona.** (Nous habitons à Barcelone.)
- **No como carne.** (Je ne mange pas de viande.)
- **Los libros están en la mesa.** (Les livres sont sur la table.)
