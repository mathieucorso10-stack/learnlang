# Leçon 4 — SER vs ESTAR, famille et description

## La grande difficulté n°1 de l'espagnol

C'est LE point qui déstabilise le plus un francophone : l'espagnol a
**deux** verbes pour "être" là où le français n'en a qu'un (*être*).
Bonne nouvelle : la logique, une fois comprise, est simple et
redoutablement utile.

- **SER** → pour ce qui est **permanent, une identité, une caractéristique
  essentielle**.
- **ESTAR** → pour ce qui est **temporaire, un état, une localisation**.

## Le verbe ESTAR (présent)

| | Espagnol |
|---|---|
| yo | est**oy** |
| tú | est**ás** |
| él/ella/usted | est**á** |
| nosotros | est**amos** |
| vosotros | est**áis** |
| ellos/ustedes | est**án** |

## Quand utiliser SER

1. **Identité / origine / nationalité** : *Soy Mathieu. Soy francés.*
2. **Métier** : *Soy profesor.*
3. **Caractéristique physique ou de caractère durable** : *Ella es alta.*
   (Elle est grande.) *Es simpático.* (Il est sympa.)
4. **Matière, possession** : *La mesa es de madera.* (La table est en bois.)
5. **Heure et date** : *Son las tres.* (Il est trois heures.)

## Quand utiliser ESTAR

1. **Localisation** (toujours, même permanente !) : *Madrid está en España.*
   (Madrid **est** en Espagne — même si c'est permanent, on utilise *estar*
   pour situer un lieu.)
2. **État temporaire, humeur, santé** : *Estoy cansado.* (Je suis fatigué.)
   *Estoy contento.* (Je suis content.) *¿Cómo estás?* (Comment vas-tu ?)
3. **Résultat d'une action, état ponctuel** : *La puerta está abierta.*
   (La porte est ouverte.)

## Le piège classique : le même adjectif change de sens

| Avec SER | Avec ESTAR |
|---|---|
| **Es aburrido.** (Il est ennuyeux — un trait de caractère) | **Está aburrido.** (Il s'ennuie — un état temporaire) |
| **Es listo.** (Il est intelligent) | **Está listo.** (Il est prêt) |
| **Es malo.** (Il est méchant — nature) | **Está malo.** (Il est malade — état) |
| **Es rico.** (Il est riche) | **Está rico.** (C'est délicieux — pour un plat) |

👉 Le français **être** ne t'aide pas ici, il faut vraiment intégrer cette
logique permanent/essentiel vs temporaire/état. C'est le principal effort
de mémoire de tout le cours — mais une fois acquis, il ne te lâchera plus.

## La famille (la familia)

| Espagnol | Français |
|---|---|
| madre / mamá | mère / maman |
| padre / papá | père / papa |
| hermano / hermana | frère / sœur |
| hijo / hija | fils / fille |
| abuelo / abuela | grand-père / grand-mère |
| tío / tía | oncle / tante |
| primo / prima | cousin / cousine |
| esposo/marido / esposa/mujer | mari / femme |

⚠️ Faux-ami : espagnol **mujer** = femme (aussi épouse). Et attention à
**embarazada** = enceinte (grossesse), un faux-ami fréquent avec l'anglais
*embarrassed* — un piège classique quand on parle aussi anglais.

## Adjectifs : accord en genre et en nombre

L'adjectif s'accorde toujours avec le nom qu'il qualifie.
- **alto / alta / altos / altas** (grand)
- **inteligente / inteligentes** (invariable en genre, mais varie en nombre)

Exemples :
- **Mi hermano es alto.** (Mon frère est grand.)
- **Mi hermana es alta.** (Ma sœur est grande.)
- **Mis padres están contentos.** (Mes parents sont contents.)

## Phrases à retenir

- **Soy de Francia, pero ahora estoy en España.** (Je suis de France, mais
  maintenant je suis en Espagne.) — beau contraste ser/estar dans une
  seule phrase !
- **Mi madre es médica y está muy ocupada.** (Ma mère est médecin et elle
  est très occupée.)
- **¿Dónde está tu hermano?** (Où est ton frère ?)
- **Estoy cansado pero estoy contento.** (Je suis fatigué mais content.)
